Account phone verification (SMS OTP)

Public documentation of the web opt-in used when a signed-in EdgeTilt member verifies their mobile number. Messages are one-time passcodes for account security only. No marketing.

Verify your phone

Product path: EdgeTilt → Settings → Account info → Verify phone. This static page mirrors the consent UI for carrier review.

By tapping Send verification code, you confirm the number belongs to you and you consent to receive transactional OTP texts only. No promotional or marketing messages are sent from this program. Terms of Service · Privacy Policy

Sample message
Your EdgeTilt verification code is 482913. It expires in 10 minutes. Do not share this code with anyone. Reply STOP to opt out, HELP for help.
Opt-in summary for reviewers
  • Type: Web form on EdgeTilt after the user signs in (Account settings).
  • Consent: Unchecked checkbox required before Send verification code. Checkbox is never pre-selected.
  • Use case: Two-factor / phone verification one-time passcodes only.
  • Opt-out: Reply STOP. Support: Reply HELP or email support@edgetilt.com.
  • Policies: https://edgetilt.com/terms?from=public · https://edgetilt.com/privacy?from=public
